# Taehyun Kim — Robotics Research Portfolio

Multi-page static website for GitHub Pages.

Upload all files and folders in this directory to the root of:
`taehyunkim98/taehyunkim98.github.io`

Pages:
- index.html — Home
- research.html — Research
- projects.html — Projects
- publications.html — Publications
- cv.html — CV
- about.html — About / Contact

For videos, place MP4 files under `assets/videos/` and replace placeholder blocks with `<video>` elements.
